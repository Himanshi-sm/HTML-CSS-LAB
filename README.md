## About the Project

This repository contains 15 HTML5 and CSS3 practical assignments completed as part of the **BCS554 – HTML & CSS Development Lab** in my B.Tech Computer Science and Engineering program.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Live Server
- Git & GitHub

## Project Structure

```text
HTML-CSS-LAB/
│
├── Lab1/
├── Lab2/
├── Lab3/
├── ...
├── Lab15/
│
└── README.md
```

Each lab folder contains:

- `index.html` – HTML source code
- `style.css` – CSS styling
- `README.md` – Practical details
- `images/` – Output screenshots

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Select any Lab folder.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.

## Learning Outcomes

- HTML page structure and elements
- CSS styling and selectors
- Tables, lists, forms and hyperlinks
- Layouts and positioning
- Responsive web design
- Git and GitHub basics
