Lab 2: Pushing and Cloning a Repository

BCS554 - HTML & CSS Development Lab

Objective

To learn how to connect a local Git repository with GitHub, push project files to GitHub and clone an existing repository.

Task 1: Connect a Remote Repository

A remote repository is a version of the project hosted on GitHub. We connect it with our local repository using the git remote command.

Git Commands:

git branch -M main

git remote -v

Replace USERNAME and REPOSITORY with your actual GitHub username and repository name.

Task 2: Push Code to GitHub

Pushing means uploading local project changes to the remote GitHub repository.

Git Commands:

git add .

git commit -m "Upload practical files"

git push -u origin main

After successfully pushing, open your GitHub repository to check the uploaded files.

Task 3: Clone a Repository

Cloning means downloading a copy of an existing remote repository to your local computer.

Git Command:

git clone https://github.com/USERNAME/REPOSITORY.git

After cloning, open the downloaded project folder in Visual Studio Code.

Conclusion

In this practical, I learned how to connect a local repository to GitHub, push files to a remote repository and clone an existing repository.
