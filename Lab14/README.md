# Lab 14: CSS Grid Layouts

**Subject:** BCS554 - HTML and CSS Development Lab

## Objective
To understand CSS Grid and create structured,
responsive webpage layouts.

## Tasks Covered

### Task 1: Grid Container and Grid Items
Used display: grid, grid-template-columns and gap
to arrange elements in rows and columns.

### Task 2: CSS Grid Gallery Layout
Created a gallery containing three cards using CSS Grid.

### Task 3: Responsive Grid Layout
Created a responsive page layout using grid-template-areas
and CSS media queries.

## Technologies Used
- HTML5
- CSS3
- VS Code
- Web Browser

## How to Run
1. Open index.html in a web browser.
2. Observe the grid container.
3. Explore the gallery layout.
4. Resize the browser to test responsiveness.
